TILTUP

Privacy policy for the Tilt Up Chrome extension and the Tilt Up web version.
Effective date: 2026-11-10.

SUMMARY

Tilt Up does not collect, transmit, sell or share any personal or sensitive user data. It has no accounts, no sign-in, no analytics, no tracking, no cookies, no advertising and no third-party code. Everything the game remembers stays in your own browser.

DATA STORED ON YOUR DEVICE

To remember your progress, the game saves the following in your browser's local storage (the extension uses chrome.storage.local; the web version uses the page's local storage):

  • the code of the last level you played, so the game can reopen it;
  • your best time and number of drops for each level code you have cleared;
  • the level codes you chose to save, with the time you saved them;
  • the difficulty you last picked.

This is game data, not personal information. It is never sent to us or to anyone else, and we have no way to see it.

PERMISSIONS

The extension asks for one permission, storage, used only to save the game data listed above. It does not read or change the web pages you visit, and it has no access to your browsing history, tabs, location or other information.

CLIPBOARD

When you press SHARE, the game writes a short challenge text (a level code, your time and, where available, a link to that level) to your clipboard. When you paste into the game, it looks at the pasted text on your device only to find a level code in it. The game never reads your clipboard on its own, and nothing you copy or paste is sent anywhere.

SHARING WITH THIRD PARTIES

We do not sell, rent, transfer or share user data with anyone, because we do not collect any. The extension contains no third-party scripts, ad networks or analytics.

The web version is hosted on GitHub Pages. As with any website, GitHub's servers may record technical information such as your IP address when your browser loads the page. That is handled under GitHub's privacy statement; we do not receive or use those records. On the web version, the GET IT FOR CHROME button opens the Chrome Web Store with a label (utm_source=web) so the store can count installs that came from this page. It carries no information about you.

LIMITED USE

The use of information by Tilt Up complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

KEEPING AND DELETING YOUR DATA

Game data stays in your browser until you remove it. You can delete it at any time:

  • remove a saved level with the × next to it;
  • uninstall the extension, which deletes all of its stored data;
  • for the web version, clear this site's data in your browser settings.

CHILDREN

Tilt Up is suitable for all ages. Because it collects no personal information from anyone, it collects none from children.

CHANGES

If this policy changes, the new version will be posted on this page with a new effective date. If the game ever started handling user data, this policy and the store listing would be updated before that change shipped.

CONTACT

Questions about this policy: use the support tab on the Tilt Up page in the Chrome Web Store.
