# Tilt Up

A tiny tilt-the-bar arcade game for Chrome, also playable on the web.
Hold **J** / **K** to raise each end of the bar and roll the ball into the lit hole.

```
npm test        # checks, build, smoke test
npm run build   # dist/tilt-up-<version>.zip and dist/web/
npm run serve   # play dist/web at http://localhost:8080
```

To try the extension, open `chrome://extensions`, turn on Developer mode, click **Load unpacked** and pick this folder.
